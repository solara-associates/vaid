# Session close-out — 2026-07-28 (Solara / VAID)

State document for whoever continues this work, including the author tomorrow.
**Verified facts only. No recommendations.**

## What was found and fixed

- **Revocation seam: shipped-but-broken, not missing.** A revocation seam existed but
  did not hold; it was replaced with a three-state, lineage-aware seam
  (NotRevoked / Revoked / Unavailable), fail-closed, revoking a parent revokes its
  children. Frozen conformance vectors were not changed.
- **Public-key document verification did not exist at all.** Added: `verify_vaid_authenticity`
  (Rust + Python) and Python `vaid-pop` `verify_signed_payload` — verifying a VAID's
  authenticity from the issuer's public key, no issuer instance.
- **Site copy overclaimed on eight pages, with one understatement.** Seven pages
  asserted verification (document / authority / lineage "on sight") that does not
  ship; one page (`/standard`) called the reference mint "on the roadmap" while
  `vaid-mint` was shipped and installable. Corrected and deployed to prod: claims
  scoped to what ships — request/action proof-of-possession, checkable by a holder of
  the signer's public key.
- **The framework-governance claim was true at code level but unproven** until a dated
  LIVE run existed. It is now backed by the phase1e conformance artifact.
